# Architecture Decision Records (ADR)

Directorio para registrar las decisiones de arquitectura del proyecto. Cada decisión relevante se documenta en un archivo `ADR-XXX-titulo.md`.

## Plantilla

```
# ADR-XXX: <Título corto y descriptivo>

- **Fecha**: YYYY-MM-DD
- **Estado**: Aceptado | Propuesto | Reemplazado por ADR-YYY

## Contexto
<Problema u oportunidad que motiva la decisión>

## Decisión
<Qué se decidió y por qué>

## Consecuencias
<Impactos positivos, negativos y pendientes>
```
